# OllamaModelTester WEB


Built a web application with `OllamaModelTester` PIP package using `FastAPI` as backend and `React` with JSX (JavaScript XML) as frontend.

`OllamaModelTester` is a comprehensive Python framework for testing, evaluating, and visualizing Ollama language models with built-in hallucination detection, performance metrics, and Google BigQuery integration.


## Installation

### Backend commands (Windows OS)

```console
$ python -m venv venv
$ .\venv\Scripts\activate
$ python -m pip install --upgrade pip
$ pip install OllamaModelTester
$ pip install -r requirements.txt
$ python .\app.py
```

### Frontend commands (Windows OS)

```console
$ npm install
$ npm run dev
```

## Access the web application

After installation, setup and run is done you can access the web app:

- `http://localhost:3000/` - Access frontend
- `http://localhost:3001/` - Access backend
